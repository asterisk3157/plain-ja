# UI の文言

Web 画面やアプリのボタン、ラベル、見出し、空の欄、案内やエラーの文に当てる決まりです。共通の決まり(SKILL.md の1〜10)に加えて当てます。

## 置くもの

1. **使われない要素は置かない**:ユーザーが使わないボタン、欄、検索は置きません。置くか迷ったら、何のための要素かを1行で言えるかで決めます。(例:使うか分からない「タスクを頼む」ボタン、会話の検索、ゲーム画面の上の催しの名前を外す)
2. **作ると決めた欄は「準備中」で残す**:まだできていない画面や欄は、消さずに「準備中」の印を付けて残します。消すかどうかはユーザーが決めます。
3. **見れば分かることを書かない**:数字やグラフで分かることを、判定の文、凡例、印で繰り返しません。(例:「問題ありません / 気にしておくことがあります」の判定と「確認事項」の一覧を外す、グラフの横の「気にする温度」を外す、予定ごとの「決まった予定」の文字と色の見方の欄を外す、カレンダーの空き時間に「空き」と書かない、予定に「頭を使う」のような分類を出さない)
4. **内部の名前を出さない**:サーバーの機械の名前、内部の状態の名前は出さず、ユーザーが見分けたいことだけを短く出します。(例:「アプリのサーバーの機械 host-01」→「ホストマシン」、表示は「ローカルホスト」か「サーバー」の2択)
5. **左の縦線の飾りを使わない**:カード、予定、引用、お知らせの左側に、色の付いた縦線(`border-left` のアクセント)を付けません。区別が要るときは、背景の色や見出しで分けます。

## 言葉

6. **何が起きたかと、することだけ**:画面の文は、何が起きたかと、ユーザーがすることだけにします。(例:「〜を断ってください」を外し、「許可の画面を開けませんでした」とだけ書く)
7. **見出しの横に説明を並べない**:ラベルや見出しに、かっこの補足や説明の文を付けません。(例:「作業フォルダ 12件(ほかに使っていないもの 5件)」→ 見出しは「作業フォルダ 12件」、ボタンを「最近使っていない作業フォルダを表示 · 5件」)
8. **ラベルはすることを言う**:入力欄や選択肢のラベルは、それで何をするかを言います。何も選ばない状態は「(選択なし)」にします。押したあとに出るものは、ラベルと合わせます。(例:デバイス → このデバイスを登録、(選ばない)→(選択なし)、「すべてのゴール」を押したらゴールの一覧を出す)
9. **ボタンと欄の名前はふつうの言葉**:短い動詞か名詞にし、意味の取りにくい言い回しは使いません。(例:「すべての機械」→「全体」、「分けたナレッジと手順」→「手順」、「ゴールなしのタスク」→「ゴールのないタスク」、「段」は使わない)
10. **指す言葉は名前で**:「この機械」「ここ」のように、どれを指すかが分からない言葉を、見出しやラベルに使いません。(例:「この機械」→「アプリのサーバー」)
11. **量は決まった言葉と単位で**:測った値は、ふだん画面で見る言葉にそろえます。割り当てがある量は「使用量 / 割り当て」と使用率で出し、意味のない最大値は付けません。稼働時間は d:hh:mm にします。(例:「使用中の時間」→「使用率」、メモリの「空き」→「利用可能」、VM「2 / 3」→「2台」、「稼働 12日」→「稼働時間 12:04:31」)
12. **状態は短い名詞で**:成功・失敗・停止のような状態は、文にせず短い名詞にします。(例:「うまくいきました」→「成功」、「止めてある」→「停止」)
13. **画面の言い回しで書く**:空の欄や案内の文は、話し言葉や作業の報告ではなく、画面でよく見る言い回しにします。空の欄が並ぶときは「まだありません」を1つだけ出します。(例:「図のタスクを押すと、ここにくわしく出ます」→「図のタスクを選ぶと、詳細が表示されます」、「長いので、ここで切りました」→「長いため、途中までを表示しています」、「見直す日(10/26)が来ています」→「10/26 に見直す日が来ました」)
14. **自然なあいさつ**:最初の画面やログインの画面は、ふつうの言い回しにします。(例:「ログイン」→「〇〇へようこそ」)
15. **画面に出る言葉はすべて日本語**:エージェントの途中のメモ、ツールを使う前の一言など、画面に流れる文も日本語の短い1文にします。(例:「Verify instances, then delete old.」→「予定を確かめてから、古いものを消します」)

## 見直しの順

1. 画面の要素を全部書き出し、1〜3で外せるものを外します。
2. 残った文に6〜15を当てます。
3. 外した要素と直した文を、「直す前 → 直したあと」の一覧で見せます。
